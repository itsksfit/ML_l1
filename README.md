# ML_L1

A beginner-friendly Machine Learning project focused on exploring and analyzing the **Medical Insurance dataset**.

## 📌 Current Work
- Data loading using Pandas
- Exploratory Data Analysis (EDA)
- Dataset shape and basic information
- Statistical analysis
- Missing-value checking
- Feature inspection
- Data visualization using Seaborn and Matplotlib

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Files
- `Untitled.ipynb` — Main ML/EDA notebook
- `insurance.csv` — Dataset

## 🚀 Future Work
This project will be expanded with data preprocessing, feature engineering, visualization, machine learning models, and model evaluation.
